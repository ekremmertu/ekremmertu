## Nasıl çalışıyorum

- **Döngünün tamamı bende:** ürün tanımı, kapsam, akışlar, test, mağaza incelemesi, yayın ve canlı operasyon.
- **Kodumun çoğunu AI ajanları yazıyor.** Klasik eğitimli bir mühendis değilim ve öyle olduğumu söylemiyorum. Görevi ben tanımlarım, kontrolleri ben koyarım, neyin yayına çıkacağına ben karar veririm.
- **Kanıta bakarım:** testler, derlemeler, mağaza onayları ve ürünün canlıdaki davranışı.
- **Modelin etrafındaki sistemi kurarım:** gerçek yazılımı süren uzman ajanlar, özel MCP araçları ve otomatik test.

Geçen yılki 800'den fazla katkımın çoğu özel ürün repolarında. Bu işleri görüşmede gösterebilirim.

**Teknolojiler:** Swift · SwiftUI · Next.js · TypeScript · Supabase · Python · FastAPI · Claude · MCP · Playwright
